대시보드 뒤의 데이터 흐름을 보는 2시간

시스템 구조와 데이터 연동을 이해하고, 실제 데이터가 대시보드에 연결되는 과정을 강사 시연으로 확인하는 2시간 시연 중심 과정입니다.

01

구조부터 이해

프론트엔드·백엔드의 개념과 역할, 데이터 연동과 파이프라인, 대시보드 개발 흐름을 정리합니다.

02

연동 과정을 시연으로

EAP를 통한 개인정보 제외 데이터 연동, GCP 키 기반 인증·조회, 대시보드 연결 과정을 직접 보여드립니다.

03

운영 관점까지

데이터 갱신·권한·유지보수 유의사항을 짚고, 현업 적용에 대한 질문을 함께 나눕니다.
